# Portal Paroquial

Portal web institucional para uma paróquia, com uma experiência pública elegante e uma área administrativa para gestão de conteúdos e usuários.

## Sobre o projeto

A proposta atual do projeto é oferecer um portal moderno, acolhedor e organizado para a comunicação paroquial, incluindo:

- página pública com apresentação institucional, notícias, eventos e conteúdos relevantes;
- navegação por seções como contatos, documentos, transmissões e rádio;
- área administrativa para gestão de conteúdo e acesso restrito à equipe;
- interface com identidade visual inspirada em um ambiente paroquial clássico e sóbrio.

## Funcionalidades principais

- layout público com header, footer e páginas informativas;
- autenticação para acesso à área administrativa;
- sidebar de navegação para gestão de conteúdos e configurações;
- rotas organizadas para notícias, eventos, transmissões, documentos e usuários.

## Tecnologias principais

- React + TypeScript
- Vite
- React Router DOM
- TanStack Query
- Tailwind CSS
- Radix UI
- PWA

## Como executar localmente

1. Instale as dependências:

```bash
npm install
```

2. Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

3. Acesse no navegador:

- http://localhost:5173

## Scripts disponíveis

- `npm run dev`: inicia o servidor de desenvolvimento
- `npm run build`: gera build de produção
- `npm run preview`: sobe preview da build
- `npm run lint`: executa lint e corrige quando possível
- `npm run test`: executa testes
